# hack-6d4719b0-i-got-love

Hackathon team repository for трека «Мияги — I Got Love».

## Запуск интерфейса

Требуется Node.js 20.19+ и pnpm.

```bash
pnpm install
pnpm dev
```

Vite напечатает локальный адрес приложения. Production-сборка проверяется командой:

```bash
pnpm build
```

## Демо-сценарий откликов

1. Откройте раздел «Отклики»: в нём есть пять примеров командных предложений к опубликованной задаче.
2. Вручную выберите одну или несколько команд. Для другого предложения нажмите «Отклонить».
3. У выбранной команды нажмите «Подтвердить этап». Команда получит 10 баллов, а предложение покажет подтверждение.
4. Обновите страницу: решение и подтверждение сохраняются в браузере, поэтому повторно начислить баллы нельзя. Баллы команды также видны в разделе «Команды».
5. Через «Добавить отклик» создайте ещё одно предложение с идеей, планом, сроком и ссылкой на прототип. Количество откликов не ограничено.
6. В разделе «Команды» проверьте пять профилей и поиск по интересам, навыкам и технологиям.

Профили и отклики в этом демо — синтетические данные. Сохранение выполняется в `localStorage`; конструктор и каталог задач пока представлены экранами-заглушками. Поля `Team` и `Proposal` соответствуют общему контракту из `TEAM_PLAN.md`.
