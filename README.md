# hack-6d4719b0-i-got-love

MVP для публикации бизнес-задач, командных откликов и ручного подтверждения прогресса.

## Запуск

Нужны Node.js 20.19+, pnpm и Python 3.10+.

Сначала установите зависимости и подготовьте демонстрационную базу:

```powershell
pnpm install
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m backend.seed
python -m backend.team_proposals
```

Запустите API в первом терминале:

```powershell
uvicorn backend.integration:app --reload --port 8000
```

Запустите React-приложение во втором терминале:

```powershell
pnpm dev
```

Откройте адрес Vite из вывода команды. Vite перенаправляет `/api` в FastAPI на порту 8000. API конструктора, каталог и команды используют SQLite; по умолчанию база находится в `backend/app.db`. Для отдельной базы задайте переменную `APP_DB_PATH`.

Production-сборка интерфейса:

```powershell
pnpm build
```

## Демо-сценарий

1. В «Конструкторе» опишите задачу. Ответьте на уточняющие вопросы или оставьте некоторые поля пустыми, проверьте карточку, подтвердите её и опубликуйте.
2. Откройте «Каталог задач». Опубликованные задачи доступны независимо от рейтинга; проверьте сортировку и фильтры по теме и уровню. Нажмите «Откликнуться» у нужной карточки.
3. В «Откликах» сравните пять примеров предложений для выбранной задачи. Откройте форму, выберите команду и отправьте ещё один отклик с идеей, планом, сроком и ссылкой на прототип.
4. Вручную выберите несколько предложений, а одно отклоните. Автоматического назначения нет.
5. У выбранной команды нажмите «Подтвердить этап». Команда получит 10 баллов. Повторный запрос или обновление страницы не начислит их ещё раз; итог также виден в профиле команды.
6. Откройте «Команды»: доступны пять синтетических профилей и поиск по интересам, навыкам и технологиям.

Чтобы начать демо заново, остановите API, удалите `backend/app.db` и повторите две команды `python -m backend.seed` и `python -m backend.team_proposals`.

## Интеграция

Общая навигация находится в `src/App.tsx`. Экран каталога подключает `frontend/src/Catalog.tsx` из PR #1; экран конструктора — `task_builder/frontend/src/TaskBuilder.tsx` из PR #2. Обе части используют один API и базу после интеграции через `backend/integration.py`.

Схема `Task` и поля `Team`/`Proposal` следуют `TEAM_PLAN.md`. Профили, отклики, ручное решение бизнеса и однократное начисление прогресса обслуживаются `backend/team_proposals.py`. Начисление меняет только баллы команды; рейтинг задачи не меняется.
