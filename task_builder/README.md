# Конструктор бизнес-задачи

Модуль общего приложения Лавлаб: описание, уточняющие вопросы, черновики, подтверждение и публикация. Запускайте проект **из корня репозитория** по [основному руководству](../README.md).

Отдельный сервер `task_builder.server:app` больше не поддерживается. Конструктор подключается через `task_builder.server.router` к `backend.integration:app`, где действуют сессии, проверка источника запросов и ограничения размера данных. Все модули используют общую базу `APP_DB_PATH`; старый параметр `TASK_BUILDER_DB_PATH` не используется.

## Запуск разработки

После установки зависимостей из основного руководства:

```sh
source .venv/bin/activate
python -m backend.seed
python -m backend.team_proposals
npm run dev:api
```

Во втором терминале из корня проекта:

```sh
npm run dev
```

Откройте адрес Vite, зарегистрируйтесь с ролью «Бизнес» и перейдите в конструктор. В Windows используйте Python из `.venv\Scripts\python.exe`, как описано в основном руководстве.

## Права и сценарий

Бизнес видит и редактирует только собственные карточки. При создании сервер назначает владельца из текущей сессии. Чужие и прежние демонстрационные карточки нельзя присвоить себе. Анонимные запросы к конструктору получают 401, другая роль или владелец — 403.

Введите описание, ответьте на вопросы, укажите название, сохраните и подтвердите карточку, затем опубликуйте её. Сохранение правок черновика снимает подтверждение. Подтверждённое изменение опубликованной карточки пересчитывает рейтинг, сохраняя отклики. Исходное описание и ответы переносятся в карточку без добавления неизвестных фактов.

## Уточняющие вопросы

Полные настройки `AI_API_URL`, `AI_API_KEY`, `AI_MODEL` включают внешний провайдер. Иначе заданный `OLLAMA_MODEL` включает локальную модель; адрес задаётся через `OLLAMA_BASE_URL`. Без модели или при ошибке доступны стандартные вопросы с объяснением причины.

Секретный ключ остаётся на сервере. Промпт и JSON-схема находятся в `server.py`. Ответ содержит 3–5 вопросов по разным полям; утверждения вместо вопросов отклоняются. Размер ответа ограничен 64 КиБ, вопроса — 500 символами. Одновременно обрабатываются до двух запросов генерации; при перегрузке возвращается 429. Перенаправления запросов к провайдеру запрещены.

## Контракт и проверки

Полные маршруты, поля, статусы и ограничения описаны в [API_CONTRACT.md](../API_CONTRACT.md). Конструктор экспортирует React-компонент `task_builder/frontend/src/TaskBuilder.tsx`; основная навигация подключает его с текущим пользователем.

```sh
python -m unittest task_builder.test_server backend.test_permissions backend.test_integration -v
npm run build
```

Проверки используют временные базы и реальные тестовые регистрации. Вызовы внешних моделей в автоматических тестах имитируются.
